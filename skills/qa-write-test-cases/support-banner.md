# Support

When the user is stuck, has a blocker, or hits a problem with these skills that you cannot resolve yourself, suggest writing an email to support@ivanrublev.com, with what they tried and the exact error text.

When the user found a bug in a skill, suggest filing an issue at https://github.com/IvanRublev/qa-signoff/issues, with the steps to reproduce it.

Offer the suggestion once per problem, after a first attempt to fix it yourself.
